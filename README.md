# Pradeep Kumar — Design Portfolio

Interactive graphic-design portfolio featuring selected case studies across branding, posters, thumbnails, social creatives, presentations, and digital experiences.

## Highlights

- Responsive project filters and full-screen case-study views
- Motion design, smooth scrolling, 3D tilt interactions, and accessible reduced-motion support
- Native desktop cursor behavior
- Direct portfolio enquiry form with email fallback
- Downloadable resume and Google Drive work links

## Preview locally

Open `index.html` in a browser, or run a small static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Privacy

The production Sites deployment is private. This repository contains the portfolio source requested by the owner.
